# Original prototype

[original-prototype.py.txt](original-prototype.py.txt) preserves the original
`Enigma M3 Decrypter.py` byte for byte. The `.txt` suffix makes its role as a
readable historical appendix explicit; it is not imported, tested as current
application code or needed by the workbench.

This is an unfinished personal experiment. Its creation date and successful
recovery of a historical message have not been established. The old filename
does not establish full M3/M4 support. See the [project history](../docs/project-history.md)
for how the revision developed from the original curiosity.

- Original size: 10,950 bytes.
- SHA-256: `f962ebf13379011174bba0f0e173f86bc3649c7fd2fcf23c29f890ddab90e08d`.

The original comments and code are retained as historical material. Current
behaviour, test results and supported settings are documented in the main README.
